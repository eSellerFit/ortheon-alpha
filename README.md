# ortheon-alpha-
Ortheon Alpha is an AI-native career transition decision-support prototype.

The Alpha version helps users at a career crossroads generate a structured career direction report based on:

- CV competence extraction
- Career anchor assessment
- Financial viability
- Decision archetype
- Role durability / future resilience
- Top career direction recommendations

## Alpha Scope

Included:
- Static website
- Assessment form
- PDF CV upload
- Make automation
- Airtable records
- AI-based CV extraction
- AI-based report generation
- HTML report page
- Feedback capture

Excluded:
- User accounts
- Payments
- Coach dashboard
- Full SaaS admin portal
- Complex dynamic map
- PDF export

## Architecture

Frontend: Vercel + HTML/CSS/JS  
Automation: Make  
Data: Airtable  
File storage: Google Drive  
AI: OpenAI / Claude API  
Reports: HTML + SVG
